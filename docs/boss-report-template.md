# Report material for `/boss rehearse`

Drop one markdown file per upcoming report into `inputs/boss-profile/reports/`.
The simulator reads this verbatim alongside `profile.md` and the last 3 meeting
notes, then drills you in the boss's style.

Free-form Markdown is fine. Using `##` headings (e.g. "What I did this week",
"Numbers", "Next steps", "Open questions") helps the simulator chunk questions
by section and pick the weakest spot to grill first.

---

# <topic — short, e.g. "Q2 progress + paper plan">

## What I did this week / since last meeting

- <bullet 1>
- <bullet 2>

## Numbers / results

| metric | value | baseline | delta |
|---|---|---|---|
| <e.g. throughput> | <X> | <Y> | <+Z%> |

## What's next

- <plan item 1>
- <plan item 2>

## Open questions for him

- <question 1>
- <question 2>

## Things I'm worried he'll push back on

<honest pre-mortem — these become the simulator's first targets>
